## CIA Triad:
It is foundation of information security. It is like main pillars of the cybersecurity. CIA Traid has Confidentiality, Integrity and  Availability
- Confidentiality:- It ensures that information is only sees by authorized persons.   
- Integrity:- It ensures that information is not altered or modified by anyone.
- Availability:- It ensures that systems and information are accessible when required.
## Explore Threat Types:
- Phishing:- Phishing performs by Hackers to reveal sensitive information of users by trick them.
- malware:- Malware is a type of malicious code or software designed to damage, disrupt, or gain unauthorized access to systems.
- DDoS:- DDoS stands for distributed denial of service, It floods servers with number of requests.
- SQL Injection:- SQL Injection is a web application vulnerability where an attacker manipulates an application's SQL query by supplying specially crafted input.
- Brute force attack:- Brute force attack is performs number of possible passwords to gain unauthorized access.
- Ransomware:- It is performs by hackers, unable complete system and data and demands for the ransom.
## Attack Vectors: 
- Social Engineering:- Social engineering is when an attacker manipulates a person into revealing information, clicking something, or performing an action that helps the attacker.
- Wireless Attacks:- Wireless attacks target Wi-Fi and wireless communication.
- Insider Threats:-An insider threat occurs when someone who already has legitimate access to an organization's systems or information misuses that access.
