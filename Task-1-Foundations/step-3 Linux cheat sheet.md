# Linux Cheat Sheet

| Command | Purpose | Example |
|---|---|---|
| `pwd` | Show current directory | `pwd` |
| `ls` | List files and directories | `ls` |
| `cd` | Change directory | `cd Documents` |
| `cd ..` | Go to parent directory | `cd ..` |
| `mkdir` | Create directory | `mkdir test` |
| `touch` | Create file | `touch notes.txt` |
| `echo` | Write/display text | `echo "Hello"` |
| `cat` | Display file contents | `cat notes.txt` |
| `chmod` | Change permissions | `chmod 600 notes.txt` |
| `chown` | Change ownership | `chown user file.txt` |
| `apt` | Package management | `apt update` |
| `dpkg` | Manage Debian packages | `dpkg -l` |
| `ipconfig` | shows ip information | `ipconfig` |
| `ping` | Check connectivity | `ping <ip address> ` |
| `netstat` | View network connections | `netstat tuln` |
| `traceroute` | See the path(hops) | ` traceroute example.com` |
